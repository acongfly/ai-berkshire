# 用 Codex 做行业筛选与选股：实战操作手册

本文档回答一个问题：打开 Codex 后，如何让 AI Berkshire 帮你选行业、筛股票、深度研究，并产出可复盘的报告。

## 0. 先确认环境

进入项目根目录：

```bash
cd /Users/yangshicong/self/ai-berkshire
```

首次使用或更新 skill 后执行：

```bash
python3 tools/install_ai_berkshire.py --target codex
```

启动 Codex：

```bash
codex
```

进入 Codex 后先确认：

```text
/status
/skills
```

你应该能看到 `industry-funnel`、`industry-research`、`quality-screen`、`investment-checklist`、`investment-team` 等 skills。

## 1. 该用哪个命令

| 你的目标 | Codex 命令 | 结果 |
|----------|------------|------|
| 不知道行业里有哪些公司，先看产业链 | `$industry-research 行业名` | 产业链地图 + 全球公司扫描 + 各环节头部标的 |
| 已经有一个方向，要从全市场筛到 3 家 | `$industry-funnel 行业名` | 30-60 家扫描 → ≤10 家粗筛 → 3 家终选 |
| 已经有一批股票，要快速排除差公司 | `$quality-screen 股票池` | 7 条硬指标去劣筛选 |
| 已经有 3-10 家候选，要做买入前检查 | `$investment-checklist 股票列表` | 六关 checklist + 通过/灰色/排除 |
| 已锁定一家公司，要深度研究 | `$investment-team 公司名` | 四大师并行研究 + 最终报告 |
| 想单篇完整研究，不需要团队拆分 | `$investment-research 公司名` | 四大师综合深度报告 |

最常用的路径：

```text
$industry-funnel AI算力
```

然后对终选 3 家继续：

```text
$investment-team 台积电
$investment-team 英伟达
$investment-team SK海力士
```

## 2. 推荐工作流 A：从行业到 3 只股票

适合：你有一个主题，但不知道该买谁。例如 AI 算力、创新药、机器人、核电、稳定币、AI 应用。

### 第一步：行业漏斗筛选

在 Codex 输入：

```text
$industry-funnel AI算力
```

建议补充约束，让结果更可用：

```text
$industry-funnel AI算力

要求：
1. 覆盖 A 股、港股、美股、日韩台欧，不要只看美股。
2. 第一层扫描至少 30 家公司，标注代码、市场、市值、产业链位置。
3. 第二层用 PE、ROE、经营现金流、负债率、护城河 5 条硬指标筛到不超过 10 家。
4. 终选 3 家必须说明为什么是组合互补，而不是简单按分数取前三。
5. 所有关键财务数据至少两个来源交叉验证。
6. 把报告保存到 reports/AI算力-funnel-YYYYMMDD.md。
```

预期输出：

- 全市场扫描池
- 被淘汰公司及理由
- ≤10 家精细分析
- 终选 3 家
- 核心/卫星/期权仓位建议
- 操作信号与风险

### 第二步：对终选公司做深度研究

假设终选是台积电、英伟达、SK 海力士：

```text
$investment-team 台积电
```

```text
$investment-team 英伟达
```

```text
$investment-team SK海力士
```

如果你希望 Codex 连续执行，可以这样下：

```text
请对上一步 $industry-funnel AI算力 终选的 3 家公司，逐一运行 $investment-team。
每家公司单独建 reports/{公司名}/ 目录，并输出：
- README.md
- 01-商业模式分析-段永平视角.md
- 02-财务估值分析-巴菲特视角.md
- 03-行业竞争分析-芒格视角.md
- 04-风险管理层评估-李录视角.md
- 最终报告.md
```

### 第三步：最终比较

```text
请基于刚才 3 份 $investment-team 报告，做一个横向比较：
1. 10 年确定性
2. 护城河深度
3. 当前估值安全边际
4. 最大不可逆风险
5. 最适合的仓位角色：核心 / 卫星 / 期权 / 观察
输出一个最终买入顺序表。
```

## 3. 推荐工作流 B：已有股票池，快速去劣

适合：你已经有一批候选股票，比如恒生科技、纳斯达克 100、朋友推荐的一串公司。

### 示例 1：筛一个指数

```text
$quality-screen 恒生科技指数成分股
```

更严格版本：

```text
$quality-screen 恒生科技指数成分股

要求：
1. 拉取完整成分股列表。
2. 用 7 条去劣指标筛选：10年平均ROE、5年累计FCF、利息覆盖、毛利率、OCF/净利润、净利率、股本稀释。
3. 银行/保险等特殊行业说明哪些指标不适用。
4. 输出通过、豁免通过、排除三类。
5. 对通过公司按“值得进一步深研优先级”排序。
```

### 示例 2：筛一组公司

```text
$quality-screen 腾讯, 美团, 拼多多, 快手, 阿里巴巴, 京东, 网易
```

筛完后继续做买入前检查：

```text
$investment-checklist 腾讯, 美团, 拼多多
```

## 4. 推荐工作流 C：已看好一家公司，判断能不能买

适合：你已经有目标公司，但不确定是否值得买。

### 快速版：买入前 Checklist

```text
$investment-checklist 腾讯
```

增强版：

```text
$investment-checklist 腾讯

要求：
1. 当前股价、市值、PE、前瞻 PE、PB、股息率必须联网核验。
2. 市值必须手算：股价 × 总股本，并与公开市值对比。
3. 必须输出“通过 / 灰色地带 / 不通过”。
4. 必须写出 5 句话镜子测试。
5. 如果不能用 5 句话说清楚买入理由，结论必须保守。
```

### 深度版：四大师团队研究

```text
$investment-team 腾讯
```

适合你准备真金白银下单前使用。

## 5. 推荐工作流 D：不知道选什么行业

如果你连行业都没定，可以先让 Codex 做主题比较。这个场景不一定要先调用 skill，可以直接让它组织任务：

```text
请基于价值投资框架，帮我比较以下 5 个方向未来 3-5 年的投资吸引力：
AI算力、AI应用、创新药、机器人、核电。

要求：
1. 每个方向都要列底层驱动、产业链瓶颈、主要上市标的、估值状态。
2. 不要直接给结论，先列正反两面。
3. 最后只选 2 个最值得进入 $industry-funnel 的方向，并说明为什么。
4. 涉及最新数据必须联网核验。
```

选出方向后再执行：

```text
$industry-funnel 机器人
```

## 6. 输出文件放哪里

按项目规则：

| 类型 | 位置 |
|------|------|
| 行业全景研究 | `reports/{行业名}-industry-{YYYYMMDD}.md` |
| 行业漏斗筛选 | `reports/{行业名}-funnel-{YYYYMMDD}.md` |
| 单公司深度研究 | `reports/{公司名}/最终报告.md` 等 6 个文件 |
| 单公司 checklist | `reports/{公司名}/{公司名}-checklist-{YYYYMMDD}.md` |
| 组合审视 | `reports/portfolio-latest.md` |

如果你想强制保存，直接在提示里写：

```text
请把最终报告保存到 reports/机器人-funnel-20260626.md。
```

## 7. Codex 提示词模板

### 模板 1：行业漏斗

```text
$industry-funnel {行业名}

我的目标：从全市场筛到最值得深研的 3 家公司。
范围：A股、港股、美股、日韩台欧、关键未上市公司。
要求：
1. 不预设看多，先摆数据再推结论。
2. 第一层扫描 30-60 家，标注入选原因。
3. 每个淘汰标的必须写淘汰理由。
4. 终选 3 家按组合互补性选择。
5. 关键数据两个来源交叉验证，估计值标“估计”。
6. 报告保存到 reports/{行业名}-funnel-{YYYYMMDD}.md。
```

### 模板 2：股票池去劣

```text
$quality-screen {股票列表/指数/行业}

我的目标：快速排除非一流公司，不要错杀潜在好公司。
要求：
1. 使用 7 条去劣指标。
2. 对不适用指标说明原因。
3. 输出通过、豁免通过、排除、数据不足四类。
4. 对通过公司给出下一步建议：$investment-checklist 或 $investment-team。
```

### 模板 3：买入前检查

```text
$investment-checklist {公司名或股票代码}

我的目标：判断是否值得进入买入候选。
要求：
1. 输出六关 checklist。
2. 必须有镜子测试。
3. 必须列反面论据。
4. 必须给“通过 / 灰色地带 / 不通过”。
5. 不确定就写不确定，不要用推测填确定性。
```

### 模板 4：单公司深度研究

```text
$investment-team {公司名}

我的目标：形成可用于真实投资决策的深度报告。
要求：
1. 四个视角独立分析：段永平、巴菲特、芒格、李录。
2. 财务数据必须交叉验证。
3. 市值、PE、ROE 等关键指标必须手算或用 tools/financial_rigor.py 校验。
4. 每个核心判断必须有反面论据。
5. 输出最终报告和是否值得买入的价格/仓位建议。
```

## 8. 使用纪律

1. 不要让 Codex “直接推荐一只股票”。先让它跑流程。
2. 涉及最新股价、财报、政策、新闻，必须要求联网核验。
3. 任何估值和市值都要手算校验。
4. 对信息不足的公司，允许结论是“数据不足，暂不判断”。
5. 真要买之前，至少跑完 `$investment-checklist`；重仓前建议跑 `$investment-team`。
